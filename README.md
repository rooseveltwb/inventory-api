# 📦 Inventory API

A backend inventory management REST API built with **Node.js**, **Express.js**, and **PostgreSQL**.

## 🚀 Features

* Product CRUD operations
* PostgreSQL database integration
* Data validation
* Error handling
* RESTful API design
* Environment variable configuration

## 🛠️ Tech Stack

* JavaScript
* Node.js
* Express.js
* PostgreSQL
* SQL
* Git & GitHub

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/rooseveltwb/inventory-api.git
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
PORT=3000
DATABASE_URL=your_database_url
```

Start the development server:

```bash
npm run dev
```

## 📦 Example Endpoint

**GET** `/api/products`

Returns all products in the inventory.
